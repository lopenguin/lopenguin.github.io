Does Optimality Scale?

A key piece of the deep learning revolution is the conceptual leap that, instead of explicitly modeling complex or high-dimensional phenomena, we can model it implicitly with enough data. Implicit modeling is an incredibly powerful abstraction.

We can push this abstraction into the domain of absurdity. We can apply this abstraction to convex optimization: instead of solving a convex optimization problem by explicitly taking Newton steps, what if we trained a model to predict the solution to a parametric problem? This is a somewhat absurd question: we already have mature convex optimization solvers that reliably produce good results, and in reasonable time.
